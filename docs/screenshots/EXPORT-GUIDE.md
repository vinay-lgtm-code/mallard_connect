# Exporting Screenshots from Pencil

To export the 10 UI mockup screens as PNG files:

1. Open `pencil-welcome-desktop.pen` in the Pencil desktop app
2. Select each screen frame by its node ID (listed below)
3. Right-click → Export → PNG (2x for retina)
4. Save to this `docs/screenshots/` directory
